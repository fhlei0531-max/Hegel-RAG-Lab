# HegelBench-ZH 回答评分标准

本 rubric 用于评价 Agent 对黑格尔哲学问题的回答质量。评审者应尽量先独立评分，再讨论分歧。

## 使用方法

1. 阅读题目、`required_points` 和 `forbidden_errors`。
2. 在不知道模型或系统名称的情况下阅读答案。
3. 对六个维度分别给 0-4 分。
4. 检查是否触发严重错误。
5. 写下至少一条可执行的修改意见。

## 评分维度

### 1. 概念准确性

| 分数 | 标准 |
|---:|---|
| 0 | 核心概念含义相反或严重混乱。 |
| 1 | 存在重要概念错误，正确内容不足以抵消。 |
| 2 | 大体方向正确，但缺少关键限定或混淆相近概念。 |
| 3 | 基本准确，只有轻微疏漏。 |
| 4 | 准确，并能说明关键限定和概念关系。 |

### 2. 文本与论证脉络

| 分数 | 标准 |
|---:|---|
| 0 | 错置著作、章节或编造来源。 |
| 1 | 几乎没有文本脉络，或脉络明显错误。 |
| 2 | 能指出相关著作，但没有说明问题在论证中的位置。 |
| 3 | 正确说明主要文本位置和前后关系。 |
| 4 | 准确说明文本位置、论证作用及必要边界。 |

### 3. 问题相关性

| 分数 | 标准 |
|---:|---|
| 0 | 答非所问。 |
| 1 | 主要内容偏离问题。 |
| 2 | 回答了部分问题，但遗漏核心要求。 |
| 3 | 直接回答主要问题。 |
| 4 | 完整回应问题，并处理其隐含误解。 |

### 4. 通俗性与表达

| 分数 | 标准 |
|---:|---|
| 0 | 难以理解或只是术语堆叠。 |
| 1 | 表达晦涩，解释不能帮助学习。 |
| 2 | 基本可理解，但例子粗糙或结构不清。 |
| 3 | 清晰易懂，例子没有明显歪曲概念。 |
| 4 | 能根据问题难度调节表达，并保持哲学准确性。 |

### 5. 诚实、来源与边界

| 分数 | 标准 |
|---:|---|
| 0 | 编造引文、页码、文献或虚假确定性。 |
| 1 | 把争议性解释写成无争议事实。 |
| 2 | 没有编造，但没有清楚区分原典与概括。 |
| 3 | 基本区分来源、解释和不确定性。 |
| 4 | 清楚标明证据范围、解释性质和仍需核验之处。 |

### 6. 教学价值

| 分数 | 标准 |
|---:|---|
| 0 | 只有结论，或会强化错误理解。 |
| 1 | 信息零散，不能帮助用户继续学习。 |
| 2 | 有解释，但没有诊断误解或建立概念联系。 |
| 3 | 能纠正常见误解并指出相关概念。 |
| 4 | 能帮助用户理解问题结构，并给出恰当的下一步阅读或追问。 |

## 总分解释

| 总分 | 结论 |
|---:|---|
| 20-24 | 可发布；仍可记录细节改进。 |
| 16-19 | 基本可用，需要定向修订。 |
| 10-15 | 存在明显缺陷，不建议公开作为可靠回答。 |
| 0-9 | 不可接受。 |

## 严重错误

出现以下任一项时，即使总分较高，也应标记为 `critical_failure`：

- 编造黑格尔原文、页码、章节或参考文献。
- 将核心概念解释成相反含义。
- 错置主要著作或论证阶段。
- 把有争议的后世解释冒充黑格尔无争议的原意。
- 用现代政治立场直接替代文本分析而不说明解释步骤。

## 评审者分歧

两位评审者在任一维度相差 2 分以上时，应记录分歧原因。不要简单取平均后隐藏争议；必要时修改 rubric 或题目。
