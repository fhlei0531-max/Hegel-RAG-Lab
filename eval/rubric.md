# HegelBench-ZH Agent 回答评分标准

本 rubric 评估 Agent 的原始回答，不用于给知识卡打分。评审前必须保存回答原文并隐藏模型、提示词和系统名称；不能先由人修订答案再评分。

## 评测流程

1. 固定问题、知识库版本、模型和检索配置。
2. 保存未经人工修改的模型回答及实际检索证据。
3. 隐去系统身份，由评审者独立评分。
4. 汇总错误后修改知识库、检索或提示词。
5. 在开发集复测，并在未参与调试的保留集做最终比较。

## 评分维度

每项 0-4 分：

| 维度 | 0 分 | 2 分 | 4 分 |
|---|---|---|---|
| 概念准确性 | 核心含义相反或严重混乱 | 大体正确但缺关键限定 | 准确且说明边界与关系 |
| 文本与论证脉络 | 错置或编造来源 | 指出著作但脉络较弱 | 准确说明位置、作用和边界 |
| 证据支持 | 主张与证据无关 | 部分主张受到支持 | 关键主张均由所示证据支持 |
| 解释诚实性 | 把争议写成事实 | 未编造但层次不清 | 明确区分原典、概括与解释 |
| 问题相关性 | 答非所问 | 回答部分问题 | 完整回应并处理隐含误解 |
| 教学价值 | 强化误解 | 基本可懂但结构一般 | 通俗而不失真并给出学习路径 |

## 严重错误

出现任一项即标记 `critical_failure`，总分不能抵消：

- 编造黑格尔原文、页码、章节或文献；
- 核心概念含义相反；
- 错置主要著作或论证阶段；
- 把后世有争议解释冒充黑格尔无争议原意；
- 引用真实来源但该来源不支持答案中的主张。

## 分歧处理

两位评审者任一维度相差 2 分以上，应先记录分歧原因，再判断是答案有歧义、题目不清，还是 rubric 需要修订。不要用简单平均值隐藏哲学解释分歧。
