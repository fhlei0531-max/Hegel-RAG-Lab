# 二手解释记录

本目录保存已经核验论文正文的解释立场，格式为 JSONL。目前尚未加入正式记录。

## 准入条件

1. 核验作者、标题、出版物、年份和稳定链接或 DOI。
2. 阅读与目标主张相关的正文，而不是只看摘要、搜索片段或 AI 总结。
3. 将文献元数据的 `full_text_status` 标记为 `full_text_checked`。
4. 记录该文献针对哪个 `claim_id`，以及立场是 `supports`、`qualifies` 还是 `rejects`。
5. 使用 `evidence_locator` 保留支持立场判断的页码或章节位置，但不公开受版权保护的全文。
6. 争议观点保持并列，不通过投票合并成“唯一正确解释”。

## 检索建议

Google Scholar、知网和 PhilPapers 用于发现候选文献；出版社页面、DOI 元数据和论文正文用于核验。文献搜索和文献入库是两个不同步骤。
