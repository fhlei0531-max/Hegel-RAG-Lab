# 黑格尔核心概念入口卡目录

本目录收录 150 个概念入口，其中“承认”已经有一条最小完整数据闭环，其余 149 张是等待逐条研究的导航初稿。它是一份可执行的研究排期，不是黑格尔术语大全，也不是已经通过哲学审核的百科词典。后世研究标签应进入解释立场或研究标签层，不与黑格尔原生术语混放。

## 覆盖范围

| 研究板块 | 代表性入口 | 首轮建议 |
|---|---|---|
| 逻辑学 | 存在、无、变易、本质、矛盾、概念、理念、扬弃 | 先完成“存在—无—变易”和“矛盾” |
| 精神现象学 | 意识、经验、感性确定性、知觉、自我意识、欲望、承认、异化、绝对知识 | 沿现有“承认”样例向前后扩展 |
| 哲学全书 | 逻辑学、自然、精神、主观精神、客观精神、绝对精神、习惯 | 先建立与其他著作的同名概念对照 |
| 法哲学 | 自由、意志、法、人格、所有权、道德、伦理生活、家庭、市民社会、国家 | 先完成“自由—意志—法”主线 |
| 历史哲学 | 世界历史、世界精神、民族精神、自由意识、理性的狡计、进步 | 优先核验讲演录编本与段落来源 |
| 哲学史 | 哲学、哲学史、哲学原则、发展、时代精神、希腊哲学、近代哲学 | 区分黑格尔重构与现代哲学史研究 |

完整机器可读清单位于 [`data/catalogs/hegel-core-concepts.json`](../data/catalogs/hegel-core-concepts.json)。概念卡位于 [`data/knowledge/concepts/`](../data/knowledge/concepts/)。

## 一张卡怎样变成可靠数据

每次只处理一个概念，并选择一个具体文本语境：

1. 核对德文术语、首选中文译名和异译。
2. 选择一部著作、一个章节和一个论证阶段。
3. 核对实际使用的德文版本和中文译本，创建来源定位卡。
4. 创建语境义项，说明概念在该段论证中做什么。
5. 将关键判断拆为原子主张，逐条关联来源。
6. 阅读二手研究全文，分别记录支持、限定或反对的解释立场。
7. 由哲学专业审核者先做诊断评分，再修订并做验收评分。
8. 从已审核主张中生成评测题，测试 RAG 检索和 Agent 回答。

不要把入口卡直接升为 `source_checked`。入口卡列出的“候选语境”只是后续检索线索，不是已经核实的章节定位。

## 推荐处理顺序

第一批建议围绕现有“承认”闭环处理 12 张：

```text
意识 -> 经验 -> 自我意识 -> 欲望 -> 生命 -> 承认
-> 主人与奴隶 -> 恐惧 -> 劳动 -> 苦恼意识 -> 理性 -> 精神
```

这条路线能直接扩展《精神现象学》的连续教学路径，也能较快形成一组相互引用、适合 RAG 检索和评测的问题。

第二批建议处理法哲学主线：

```text
自由 -> 意志 -> 自由意志 -> 法 -> 抽象法 -> 人格
-> 所有权 -> 契约 -> 不法 -> 道德 -> 伦理生活
-> 家庭 -> 市民社会 -> 国家
```

第三批再进入逻辑学。逻辑学概念之间依赖更密，单卡容易误导，适合在审核流程稳定后成组推进。

## 生成与检查

生成器只创建缺失文件，不覆盖已经人工修订的卡片：

```powershell
python scripts/generate_concept_hubs.py
python scripts/generate_concept_hubs.py --check
python scripts/validate_data.py
```

目录发生变化时，可以重新运行生成器补齐新卡。已存在文件会被跳过。

## 当前质量边界

- 所有批量卡均为 `drafted`。
- 德文词形、中文异译、相关概念和候选语境仍可能需要修正。
- 卡片没有直接引文、页码或经过核验的来源证据。
- 自动校验只保证结构、ID 和关联有效，不保证哲学解释正确。
- 只有完成来源核验和专业审核的语境义项与原子主张，才应进入正式 RAG 知识库。
