# 语境化哲学知识模型设计

## 目标

将单张百科式概念卡升级为可表示文本语境、解释分歧、证据来源和审核过程的知识模型。第一阶段只以“承认（Anerkennung）”建立最小完整样板，不批量扩展概念。

## 设计原则

1. 概念没有脱离语境的唯一完整定义。
2. 原典事实、转述、编者概括、学术解释和教学类比必须分层。
3. 每条关键主张必须能够关联来源定位；资料不足时明确标记待核验。
4. 不同二手研究作为独立解释立场保存，不合并为无来源的“学界认为”。
5. 内容修订评分和 Agent 盲评是两个不同流程。

## 数据层

### 概念入口

保存稳定名称、原文术语、别名、相关概念和语境卡 ID。它是导航入口，不承担跨越全部著作的唯一权威定义。

### 语境义项

将概念绑定到著作、章节、论证阶段和来源定位。正文说明这一语境中的论证功能、前置概念和适用边界。

### 原子主张

将关键断言保存为 JSONL。主张类型受控为 `textual_fact`、`paraphrase`、`editorial_summary`、`scholarly_interpretation`、`pedagogical_explanation` 或 `analogy`。每条主张记录证据、支持状态和审核状态。

### 解释立场

二手研究对特定主张的 `supports`、`qualifies` 或 `rejects` 立场单独记录。没有读到和核验论文正文前，不创建正式解释记录。

### 来源定位

来源定位保存作品、章节、段落范围、版本与定位核验状态。现代译本全文和受版权保护的论文正文不进入公开仓库。

## 审核与评分

知识内容采用“初稿诊断评分 -> 修订 -> 最终验收评分”。初始评分保留原稿问题，最终评分决定是否达到发布门槛。来源错误、伪造引文和解释冒充原意属于硬性失败，不能被总分抵消。

Agent 采用固定问题上的原始回答盲评。评审者不能先替模型修改答案；系统修改后使用相同开发集复测，并使用未参与调试的保留集做最终比较。

## 最小样板

- 一个“承认”概念入口；
- 一个《精神现象学》自我意识部分的语境义项；
- 一个待版本核验的来源定位；
- 五条左右原子主张；
- 五道开发集问题；
- 不伪造尚未完成正文核验的二手解释记录。

## 验证

验证器检查必填字段、受控枚举、ID 唯一性和跨文件引用。哲学正确性仍由人工审核负责，自动化校验不冒充专业判断。
