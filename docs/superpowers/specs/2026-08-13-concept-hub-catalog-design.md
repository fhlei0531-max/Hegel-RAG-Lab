# 黑格尔核心概念入口卡目录设计

## 目标

建立一套可逐条深化的黑格尔核心概念入口卡初稿。入口卡负责术语导航和研究排期，不把跨著作的复杂概念压缩成一个权威定义，也不冒充已经完成来源核验的语境卡。

## 范围

本轮覆盖项目指定的六类文本：《精神现象学》《逻辑学》《哲学全书》《法哲学原理》《历史哲学讲演录》和《哲学史讲演录》。概念目录采用“核心而非穷尽”的口径：收录足以支撑学习路线和后续 RAG 数据建设的高频、枢纽性术语，不宣称穷尽黑格尔全部术语。

现有“承认”完整样例保留。其他概念只生成 `concept_hub`，后续由人工逐条创建语境义项、来源定位、原子主张和评测题。

## 数据结构

机器可读目录为每个概念保存：

- 稳定 ID 与文件名；
- 首选中文名、德文术语与常用别名；
- 候选著作和章节线索；
- 相关概念 ID；
- 需要人工核验的问题。

生成的 Markdown 卡保持现有 `concept_hub` frontmatter 规范。未建立语境义项时使用空 `context_ids`，正文明确标注候选语境只用于排期。

## 生成原则

生成器默认只创建缺失文件，不覆盖任何已有概念卡。这样人工开始修订后，可继续扩展目录而不破坏已加工内容。`--check` 模式用于 CI 或本地检查目录中的卡片是否全部存在、ID 是否匹配，并检测尚未进入人工处理流程的生成卡是否偏离目录模板。“承认”完整样例作为保留卡，仅检查存在性和 ID。

## 风险控制

- 全部新卡为 `drafted`；
- 不写直接引文、页码、段落号或文献立场；
- 候选章节不作为来源定位；
- 德文词形、中文译名和相关关系仍需专业审核；
- 自动验证只证明结构和引用有效，不证明哲学内容正确。

## 验收

- 目录内每个非保留概念都生成一张 Markdown 卡；
- ID、文件名、术语字段和相关概念引用可被测试检查；
- 生成器不会覆盖现有文件；
- 全库数据验证无错误；
- 文档明确说明“核心目录”边界和逐条加工流程。
